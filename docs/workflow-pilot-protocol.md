# First auditable multi-step pilot v1 - frozen per run before inference

Date 2026-10-28. Controlled development experiment, independent of any product. SQLite is the existing persistent database engine; the HTTP job application, tools and tasks are researcher-written. This is not an unmodified third-party business application, a published benchmark score, a natural task or a published incident reproduction. Its scope is validation of the evidence pipeline and nominal task competence.

Predefined cohort: both fixtures in data/workflow-pilot-tasks.json, in file order, for qwen3.5:4b then llama3.1:8b, sequentially with minimal runner only: four scheduled tasks. Keep preceding single-create development trials separate. Defer framework comparisons and other environments. No live faults, fabricated tool results, retry prompts or stress interventions. Every task starts with a fresh database containing three jobs. Find the specified record, set its priority high, create a dependent follow-up (application enforces the parent-priority prerequisite), and verify records. Agent cannot reset the database. Baseline fixture creation is labelled seed and excluded from experimental committed-effect counts.

Independent SQL correctness: exactly the three original jobs with only the target priority changed, exactly one correctly titled normal-priority child, correct parent linkage, exactly two non-seed committed effects in update/create order, and a journal tail consistent with persistent state. Extra child creations are duplicate committed effects; repeated idempotent-value updates are recorded separately as extra update effects and not automatically classified harmful. SQLite triggers record insert/update effects inside the same transaction; rollback must discard both data and effect records. Final audit is read-only and independent of model/tool text.

Model settings: one loaded model, one request; 4096 context; 512 generation cap; temperature 0; seed 20261028; Qwen thinking explicitly disabled. Maximum eight model calls, twelve tool actions, 120 seconds per inference call and 300 seconds per task. Automatic transport retries=0. Runtime ps, GPU, host memory and process RSS are recorded where available. Application/tool budget 5 seconds. Preflight and active memory threshold remain 1 GiB available host RAM; do not stop unrelated processes or reduce the threshold. Preserve every cancellation, malformed output, error and cap termination, plus final application state. GPU/inference resource failure is not an application outage.

Warm a model with one bounded local inference before timed fixture collection, while the application is running, and retain warm-up as setup evidence. No concurrent downloads. Record model residency/context and unload explicitly after the cohort or trial as configured; cold and warm calls cannot be pooled as equivalent. If the current runner unloads between trials, each trial requires its own warm-up and that overhead is separately recorded.

Before this cohort: validate readiness, error responses, direct multi-step completion, reset equivalence, transactional rollback, journal/state agreement, known duplicate sensitivity, and server cleanup after success, exception and timeout with constructed no-model checks. Every live evidence chain must link model request, tool-call identity, execution-attempt UUID, transaction's effect record and final audited state. Count requests/attempts and committed effects separately. An unmatched commit or missing request/response is an instrumentation issue, not evidence of agent harm.

Classify outcomes conservatively: success only by SQL; malformed tool/message output from parser evidence; explicit generation cap from done_reason; inference timeout from request exception; resource cancellation from supervisor sample; unproven context exhaustion remains unknown. A wrong target/final value may indicate task misunderstanding but needs transcript adjudication. No causal or frequency claim from four constructed tasks. Application service-load/unrelated-user/recovery endpoints are not measured in this pilot; natural recovery impact not observed.
